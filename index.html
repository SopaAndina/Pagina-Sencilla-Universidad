✨ ¿Qué es la informática? La informática (del francés informatique) es la disciplina encargada del estudio, desarrollo y gestión de sistemas computacionales. Abarca hardware, software, redes y todo lo relacionado con el procesamiento digital de datos.

🔍 En esta exposición descubriremos los pilares fundamentales que hacen funcionar ordenadores, smartphones y el mundo tecnológico actual.

🖥️

Hardware

Partes físicas de un ordenador. Todo lo que se puede tocar.

  • CPU → Cerebro del PC
  • RAM → Memoria temporal
  • Disco Duro / SSD → Almacenamiento
  • Placa Base → Conexión total
  • Periféricos (teclado, ratón, monitor)
⚙️

Software

Instrucciones, programas y datos que hacen funcionar el hardware.

  • Sistema Operativo (Windows, Linux, macOS)
  • Aplicaciones (navegadores, ofimática, juegos)
  • Lenguajes de programación (Python, Java, C++)
  • Firmware - software en chips
🌐

Redes & Internet

Conexión entre dispositivos para compartir información.

  • Protocolo TCP/IP → Lenguaje común
  • DNS → Traduce nombres a direcciones IP
  • WWW → Servicios web
  • WiFi, Ethernet, Fibra óptica

🔄 Diferencias clave: Hardware vs Software

Aspecto Hardware Software
Naturaleza Física, tangible Lógica, intangible (código)
Ejemplos Monitor, disco duro, memoria RAM Word, Photoshop, sistema operativo
Durabilidad Se desgasta con el tiempo No se desgasta, puede actualizarse
Interdependencia El hardware necesita software para funcionar El software necesita hardware para ejecutarse
🧠

DATO CURIOSO: La primera programadora de la historia fue Ada Lovelace (1815-1852). Creó el primer algoritmo diseñado para ser procesado por una máquina, mucho antes de que existieran las computadoras electrónicas.

⚡

¿Sabías que…? Un microprocesador moderno realiza millones de operaciones por segundo. La informática evoluciona tan rápido que la Ley de Moore predijo que los transistores se duplican cada 2 años.

📀 Bits y Bytes

Bit = 0 o 1 (unidad mínima). Byte = 8 bits. Con ellos se representa cualquier dato: texto, imagen, sonido.

🧩 Lenguajes de programación

Permiten crear software. Bajos (ensamblador) y altos (Python, JavaScript). Traducen órdenes humanas a código máquina.

🔐 Ciberseguridad básica

Protege datos y sistemas. Uso de antivirus, firewalls, contraseñas robustas y actualizaciones.

🖱️ La informática mueve el mundo: inteligencia artificial, big data, desarrollo web y más.
